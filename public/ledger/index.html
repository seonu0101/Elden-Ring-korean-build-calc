ELDEN RING 세이브 파일 찾기

1. 키보드에서 Windows 키 + R을 누릅니다.

2. 아래 경로를 붙여넣고 Enter를 누릅니다.

%APPDATA%\EldenRing

3. 안에 있는 긴 숫자 이름 폴더를 엽니다.

4. ER0000.sl2 파일을 이 사이트에 넣으면 됩니다.

웹 브라우저 보안 때문에 사이트가 AppData 폴더를 자동으로 열 수는 없습니다. 대신 경로 복사 버튼으로 바로 붙여넣을 수 있게 했습니다.
